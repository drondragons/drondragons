## Обо мне

Раздел находится в стадии вдумчивого заполнения: хочется написать честно, коротко и без корпоративного заклинания на три абзаца.

Пока можно считать, что здесь живёт разработчик, который пишет на Python и C++, любит понятный код и периодически спорит с README до победного конца.

## Что мне интересно

- Делать так, чтобы код читался не только в день его написания.
- Разбираться, почему «оно вчера работало».
- Писать backend-логику без магии, насколько это вообще возможно.
- Иногда красиво оформлять репозитории, потому что встречают всё-таки по README.

## Куда смотреть

Пока подборка лучших проектов ещё собирается в стройную витрину. Если хочется посмотреть код уже сейчас, лучше начать с закрепленных репозиториев в профиле и проектов, где есть README, история изменений и хоть какие-то признаки заботы о будущем читателе.
